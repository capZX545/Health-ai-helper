# 🚀 Deploy NexusMed 2077 to the Web (Free)

## One-Click Deploy

1. Go to [render.com](https://render.com) and sign up (free, no credit card)
2. Click **New → Docker**
3. Connect your GitHub account → select `capZX545/Health-ai-helper`
4. Render auto-detects the Dockerfile → click **Create Service**
5. In 2-3 minutes you get a permanent URL like:
   ```
   https://nexusmed-2077.onrender.com
   ```

That URL works on ANY device — phone, tablet, computer — with ALL features.

## Android App

After deploying:
1. Open NexusMed Android app
2. Enter your Render URL (e.g., `https://nexusmed-2077.onrender.com`)
3. All 19 modules work: diseases, drugs, labs, symptoms, research, tools

## Desktop

Unchanged. Run `START.bat` locally as before — works offline.
