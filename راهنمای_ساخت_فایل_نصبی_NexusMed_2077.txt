  راهنمای ساخت فایل نصبی «نکسوس مد ۲۰۷۷» (NexusMed 2077)
  خروجی نهایی:  Output\NexusMed_Setup_v2.0.exe
════════════════════════════════════════════════════════════════════

【۱】 پیش‌نیازها (فقط یک بار نصب شوند)
──────────────────────────────────────
 ①) Python 3.10 یا جدیدتر
     • از سایت python.org دانلود کنید
     • حین نصب حتماً تیک «Add python.exe to PATH» را بزنید

 ②) Inno Setup 6
     • از سایت  jrsoftware.org/isdl.php  دانلود و نصب کنید
     • مسیر پیش‌فرض: Program Files (x86)\Inno Setup 6

 نکته: برای ساخت EXE واقعی ویندوز باید این مراحل روی «ویندوز»
    انجام شود. روی لینوکس/مک نمی‌شود Setup ویندوزی ساخت (اسکریپت‌ها
    آماده‌اند و روی ویندوز با یک دابل‌کلیک کار می‌کنند).


【۲】 ساخت فایل نصبی (فقط ۲ کلیک)
──────────────────────────────────────
 ①) پوشه‌ی پروژه را روی ویندوز Extract کنید (مثلاً D:\NexusMed)
 ②) روی فایل زیر دوبار کلیک کنید:

        Create_Setup_Installer.bat

 این فایل خودش به‌ترتیب انجام می‌دهد:
   [1/6] پیداکردن Python
   [2/6] نصب کتابخانه‌ها از requirements.txt
         (requests ،Pillow ،numpy ،scikit-learn ،pyinstaller)
   [3/6] تست کامپایل همه‌ی فایل‌های Python (py_compile)
   [4/6] ساخت دیتاست CSV و دیتابیس (در صورت نبود)
   [5/6] ساخت EXE با PyInstaller  →  dist\NexusMed2077\
   [6/6] ساخت فایل نصبی با Inno Setup

 خروجی نهایی اینجا ساخته می‌شود:

        Output\NexusMed_Setup_v2.0.exe


【۳】 نصب روی کامپیوترهای دیگر
──────────────────────────────────────
 • فایل NexusMed_Setup_v2.0.exe را به هر کامپیوتر ویندوزی ببرید
 • نیازی به Python یا اینترنت برای «نصب» نیست
 • نصب به‌صورت کاربر (بدون نیاز به دسترسی Administrator)
 • آیکون دسکتاپ + منوی استارت ساخته می‌شود
 • اولین اجرا: برنامه کاملاً آفلاین کار می‌کند (مغز داخلی)
 • برای اتصال به AI خارجی: دکمه‌ی تنظیمات API داخل برنامه


【۴】 تنظیم کلید API (برای پاسخ‌های قوی‌تر آنلاین)
──────────────────────────────────────
 ①) کلید رایگان از  https://openrouter.ai/keys  بگیرید
 ②) در برنامه: تنظیمات API → کلید OpenRouter را وارد کنید
 ③) دکمه‌ی «تست اتصال» را بزنید — پیام فارسی می‌بینید:
       اتصال برقرار است
       کلید نامعتبر است / مدل پیدا نشد / اعتبار کافی نیست /
         محدودیت درخواست / اینترنت قطع است
 ④) ذخیره — بدون نیاز به ری‌استارت اعمال می‌شود

 کلیدها فقط در فایل .env روی همان کامپیوتر ذخیره می‌شوند و
 هرگز داخل Setup یا ZIP قرار نمی‌گیرند.


【۵】 نسخه‌ی وب محلی
──────────────────────────────────────
 • شورتکات «NexusMed 2077 Web» از منوی استارت، یا
 • اجرای دستی:   python run_web.py
 • آدرس: http://localhost:2077
 • اگر پورت ۲۰۷۷ اشغال باشد، خودکار ۲۰۷۸ تا ۲۰۸۷ امتحان می‌شود


【۶】 حل مشکلات رایج
──────────────────────────────────────
 ▸ «Python پیدا نشد» → در نصب Python تیک PATH را نزاشتید؛
   Python را دوباره نصب کنید یا از Microsoft Store نصب کنید.
 ▸ «Inno Setup پیدا نشد» → مسیر ISCC را درست کنید یا Inno Setup 6
   را نصب کنید؛ سپس bat را دوباره اجرا کنید.
 ▸ آنتی‌ویروس روی EXE هشدار داد → PyInstaller معمولاً هشدار کاذب
   می‌دهد؛ فایل را Allow کنید یا از اجرای سورس استفاده کنید.
 ▸ پورت وب اشغال است → برنامه خودش پورت بعدی را انتخاب می‌کند.
 ▸ ویندوز ۷/۸ → پایتون 3.8–3.12 قدیمی‌تر نصب کنید (نسخه 3.13+
   فقط ویندوز 10/11).
